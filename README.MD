# M-power 迷你电源项目

在宿舍调试设备没有可调电源，实验室的可调电源体积大并且算是违禁物品，所以就想自己做一个可调电源，要足够迷你，能够满足调试设备的需求，并且具备恒压、恒流功能、有便携性、支持PD协议以及常见DC电源接口，XT60接口（后面可能准备看一下无人机相关的东西）。

# 记录

2025/5/27 准备开新坑，自制迷你电源。

2025/5/30 因为这个项目中开关电源比较多，这方面知识比较匮乏，准备边学边做项目。目前正在看，唐老师讲电赛的DCDC开关电源系列。

2025/7/02 一个月时间把原理图研究明白了，电流采样电路和电流PI环与电压环构成双环竞争这部分比较难理解，TL431可编程基准源可作为比较器使用，其内部vref = 2.495V。把芯片改成ESP32了，后面还想开发网页端控制（类似上一个项目），ESP32的引脚应该是刚好够用，原项目中的RTC时钟功能给去掉了（还需注意ADC2通道与WIFI不能同时使用）。目前刚刚送去打板，等待样板回来进行调试。

2025/7/15 样板调试出现BUG总结：1. 立创EDA中CSD18536封装引脚顺序错误。 2. 未接反馈环路情况下直接上电测试，电容冒烟（以后坚决不能，要把后级调试完成再LM5175上电，具体原因正在排查）3.GS8552放大器电压采样电路同相反相接反，负反馈端应该接反向输入端（目前飞线解决了）4.DAC未调试成功


2025/7/25 电容冒烟原因：焊接问题，输出短路导致电流过大。本次更改仓库更新：1.更改上次GS8552电路接错部分。2.LCD屏幕驱动NMOS必须使用低端驱动（上次画成高端了，切记）。3.ESP32软件部分添加LVGL、屏幕驱动、编码器、蜂鸣器、UI界面（SquareLine Studio 设计）、adc多通道DMA读取。

硬件部分调试记录：1.输入电容虚焊，上电能听到火花声音，一片ESP32 IO0应该是被击穿了对地电阻只有100Ω，导致程序下载进去后无法启动，一直进入下载模式。只有手工上电同时跳线接3.3能正常启动。2.LM5175电压环问题，设定DAC值后输出电压与预期不符合，输入12V输出小于8V会出现输出电压缓慢降低再突然升高，检查FB引脚为0.86V左右，手册上说0.86V是芯片的OVP电压，BOOST模式下工作正常。尝试更换频率设置电阻（原500K现在设置为350K）、补偿网络参数、DCM变成CCM模式，均无法解决。更换两篇LM5175后工作正常，buck输出电压与预期相符（可能是淘宝上买的翻新货不行，其中有一个是优信的）。目前已经基本完成硬件调试，还有电流环没有调试。


2025/7/30 本次更新软件部分，1.UI添加菜单、图表、蓝牙开关页面。2.蓝牙部分还没有调试完，ESP-IDF蓝牙协议太难懂了，蓝牙协议栈需要系统学习，现在只能实现手机蓝牙连接发送命令控制（蓝牙串口）。
